VANESSA BIRTHDAY WEBSITE

FILES
- index.html: main site
- style.css: design and animations
- script.js: countdown, gallery, envelope, music controls
- assets/frame_01.jpg ... frame_11.jpg: sample stills extracted from your uploaded edit video
- assets/song.mp3: add your chosen music file here (not included)

COUNTDOWN
The countdown target is 16 October 2026 at 00:00 WIB. If opened after that moment, the site goes directly to the gallery. If you want a different time/date, edit the `target` line in script.js.

MUSIC
Place a legally obtained MP3 you want to use at assets/song.mp3. Mobile browsers generally block autoplay, so the music button is available for Vanessa to tap.

PHOTOS
The current gallery uses 11 still frames extracted from your uploaded video as placeholders. For the best result, replace them with the original photos (keep the same filenames frame_01.jpg through frame_11.jpg, or update the `photos` array in script.js). Make sure you are comfortable sharing every photo included.

HOSTING
This is a static website and can be hosted on GitHub Pages, Netlify, or Cloudflare Pages. Upload the folder contents while preserving the assets folder. Test the published link on a phone before sending it.

ANALYTICS
No tracking script is enabled by default. If you want aggregate visit/page-view counts, create a site with a privacy-conscious analytics provider such as GoatCounter and add its official script to index.html. Do not use analytics to infer someone's feelings from visit counts; counts can be affected by refreshes, previews, and browser behavior.
